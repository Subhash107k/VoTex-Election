Project type
- Frontend: React 19, TypeScript, Vite, Tailwind CSS 4, lucide-react, motion, Recharts.
- Backend: Node.js, Express 4, TypeScript runtime via tsx, JSON body APIs, JWT, bcryptjs, Helmet, CORS, express-rate-limit, Zod, Nodemailer, Twilio, MongoDB driver.
- Database: MongoDB driver with optional MongoDB Atlas URI, plus local JSON-file fallback in src/db/data.
