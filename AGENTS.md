# AGENTS

This project uses human and automation roles to manage development, review, and deployment.

## Roles

- **Developer**: implements features, fixes bugs, writes tests, and maintains the codebase.
- **Reviewer**: reviews pull requests, verifies code quality, and checks security and compliance.
- **Tester**: validates functionality, runs automated tests, and reports regressions.
- **DevOps**: manages deployment, infrastructure, and build pipelines.
- **AI Assistant**: helps generate documentation, suggest improvements, and support code changes.
