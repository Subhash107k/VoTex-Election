# CONTEXT

This repository contains the VoTex Election project, a voting and identity verification platform built with Node.js, TypeScript, and React.

## Purpose

Provide a secure election experience with support for biometric verification, authentication, and audit logging.

## Key areas

- `server.ts` and `controllers/`: backend API endpoints and business logic.
- `middleware/`: request validation, audit hooks, and biometric consent.
- `services/`: reusable services for notifications, fraud detection, caching, and security.
- `src/`: frontend application, components, pages, and utilities.

## Audience

- Developers working on backend or frontend features.
- Testers validating election workflows.
- Security reviewers auditing authentication and vote integrity.
